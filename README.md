# Adega Bom Sabor - Frontend Dashboard

Dashboard interativo para o Sistema de Apoio a Decisao (SAD) da Adega Bom Sabor.

## Funcionalidades

- Dashboard com KPIs (clientes, produtos, vendas, faturamento)
- Visualizacao de probabilidade de churn
- Segmentacao de clientes (Premium, Sensivel a Promocoes, Ocasional)
- Alertas estrategicos
- Graficos interativos

## Tecnologias

- React + TypeScript
- Tailwind CSS
- Recharts (graficos)
- Shadcn/ui (componentes)

## Como Executar

```bash
npm install
npm run dev
```

## Configuracao

Configure a URL do backend no arquivo `.env`:

```
VITE_API_URL=http://localhost:8000
```

## Build

```bash
npm run build
```
